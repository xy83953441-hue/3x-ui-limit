# 安装、更新与日常诊断

## 安装与更新

新装使用本仓库的 `install.sh`。已安装的服务器使用菜单 **2** 或 `x-ui update`，不要通过重复安装来更新。

发布流程先执行前端构建、Go 测试、SSL/运维脚本测试，再构建全部平台。全部安装包和 `SHA256SUMS` 上传到草稿版本后才正式发布。下载中的文件不会成为“最新版”。公开版本的同名标签禁止覆盖；重新发布应使用新标签。

更新会先下载、验证校验和、检查压缩包及二进制，再停止服务。停机后备份程序、数据库目录（含 SQLite WAL）和菜单到 `/var/backups/x-ui-update.*`。替换后检查服务连续运行及本机面板端口。失败会尝试恢复旧程序、数据库和菜单并启动旧服务。成功后保留备份，确认正常后可手动清理。

自动恢复不是掉电保护；强制断电、磁盘损坏或恢复期间写入失败仍需人工处理。备份包含节点凭据，请保持目录仅 root 可读。自定义安装/数据库路径或仅绑定特定 IP 的服务器应人工升级。更新不会重新签发证书、重置账号或修改节点端口。

## 证书

新装、菜单 **19** 和 Cloudflare 菜单 **20** 共用 `scripts/lib/ssl.sh`；安装脚本内嵌相同代码以支持单条命令安装。修改后运行 `python3 scripts/sync_ssl.py`，发布检查会拒绝不同步版本。

- IP 自动证书使用短期证书，设置 3 天续期周期；域名使用 CA 默认有效期。
- HTTP 验证需公网 TCP 80 可达且申请时未被其他服务占用；程序不停止占用端口的其他服务。
- 自动申请检查 cron 服务及 ACME 任务；订阅端口是否放行由安装者选择，节点端口单独管理。
- 菜单 20 使用 Cloudflare API Token，应有对应域名的 DNS 编辑权限。凭据交给 ACME 保存以供续期，菜单不回显 Token。
- 已有证书由外部工具负责续期。跳过 SSL 保留原配置；没有 TLS 时请用 SSH 隧道或 HTTPS 反向代理访问。
- 面板和订阅的证书路径在同一数据库事务中保存，失败返回非零状态。续期后的服务重启失败也会返回错误。

设置成功、任务存在和本机防火墙放行，都不等于已验证公网访问或未来续期成功。应在真实服务器检查完整申请及续期过程。

## 新菜单

- **27 / `x-ui diagnose`**：查看服务、监听端口、防火墙临时/永久规则、证书有效期、续期任务和日志中的最近结果。不输出账号密码、私钥或订阅令牌。
- **28 / `x-ui open-node-port`**：输入并确认后仅永久放行指定 TCP 端口；不会关闭防火墙或开放整个端口范围。
- **24 / BBR**：先检查内核支持。不支持时不写入配置，不影响节点继续运行。

面板端口、订阅端口、节点端口是三回事。云平台安全组仍需在服务商控制台检查。FlClash 请复制二维码窗口中的 **Clash / FlClash** 链接，不必手动修改 `/sub/`。

REALITY 表单会检查端口范围、X25519 密钥格式、SNI、Short ID 和 Vision 传输组合；这不替代实际连接测试或目标站点可达性验证。前端检查也不是 API 的安全边界。

```sh
bash tests/install_ssl_test.sh
bash tests/operations_test.sh
node tests/inbound_validation_test.mjs
python3 scripts/sync_ssl.py --check
go test ./...
```

脚本测试使用临时目录与服务/CA 模拟，包含更新失败恢复数据库和菜单、下载失败不覆盖旧菜单、不支持 BBR 时不修改系统等场景。真实 systemd/OpenRC、防火墙、公网 CA 及 CentOS 7 端到端安装需在测试服务器另行验证。
